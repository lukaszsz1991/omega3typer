Omega 3 Typer

Aplikacja webowa do typowania wyników wydarzeń sportowych (praca inżynierska). 

Aplikacja stworzona z wykorzystaniem:
 - Django
 - PostgreSQL 
 - Bootstrap 5

Gracze typują dokładne wyniki meczów, zdobywają punkty i porównują się w rankingach globalnych, ligowych oraz w prywatnych grupach.

Kod źródłowy: https://github.com/lukaszsz1991/omega3typer
